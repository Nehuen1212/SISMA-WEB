Manual de usuario

Este manual explica de manera técnica y didáctica el funcionamiento del proyecto SISMA, sus objetivos, la forma de encender y observar la maqueta, y la manera de presentar los resultados obtenidos.

Producto Tecnológico

El planteamiento del problema llevó al desarrollo de un prototipo de simulación de sismos unidireccional (en un solo eje), al que llamamos SISMA - X1. Se trata de un carro móvil controlado mediante un microcontrolador ESP32 y un sistema GRBL, similar a los comandos de una máquina CNC.

Introducción al producto

El sistema incluye una PCB a medida y un gabinete dedicado para la unidad de control. El diseño integra de forma compacta las conexiones para comunicación serial, las etapas de potencia para las bobinas del motor y los conectores para los finales de carrera.

Programa de control

El programa de control de SISMA está diseñado para ser fácil de usar y comprender, permitiendo al usuario gestionar la generación de sismos, la ejecución y el control del prototipo. Se divide en tres secciones principales: generador de sismos, ejecución y conversión de sismogramas.

Pestaña generador de sismos

El usuario ingresa los parámetros deseados y exporta el archivo .GCODE con el botón “Generar G-CODE”.

  • Magnitud Richter: 1 a 10.
  • Ciclos: repeticiones de la onda.
  • Amplitud: 1 mm - 200 mm.
  • Velocidad: mm/s.
  • Aceleración: mm/s².

Pestaña de ejecución

Permite controlar la conexión, el movimiento manual, la carga y ejecución del archivo G-CODE y la operación del prototipo.

  • Puerto: selecciona el COM.
  • Conectar: envía “?” para iniciar la comunicación.
  • HOME: $H para establecer el origen.
  • CARGAR: carga el archivo G-code.
  • EJECUTAR: envía el archivo o reanuda la ejecución.

Pestaña de conversión de sismogramas

Desde esta pestaña el usuario puede importar un sismo en formato GeoCSV, visualizar los datos más relevantes y la gráfica del movimiento, y generar el archivo de simulación .gcode listo para ejecutarse.

Flujo e indicaciones de uso

1

Conexión y encendido

Conecte el JACK DC del gabinete a una fuente de 12V a 35V, y el simulador a la PC mediante USB micro.

2

Software

Abra la interfaz de control y acceda a la pestaña de ejecución.

3

Conexión serial

Seleccione el puerto COM correspondiente y presione “Conectar” para enlazar con el controlador GRBL.

4

Ejecución de la simulación

Generel o cargue una simulación, luego ejecute el archivo .gcode o envíe comandos G-code directamente.

Montaje de las maquetas

Se utilizan ganchos y una plataforma móvil superior con perforaciones. Se colocan los ganchos sobre las columnas inferiores, se fija la maqueta y se ajustan los tornillos parker para asegurar la estructura antes de la simulación.

Consideraciones y precauciones

  • Asegurar la correcta fijación de la maqueta antes de iniciar el movimiento.
  • No exceder los límites físicos del sistema.
  • Usar la tensión de alimentación correcta (12V a 35V).
  • Detener el uso si hay sobrecalentamiento.
  • Lubricar las varillas si el movimiento presenta trabas.
  • Desconectar por software antes de retirar el USB.
